### 6️⃣ Sayeq Suoq — *Online Car Store (Web)*
---

**Overview:**  
A fully responsive e-commerce platform for browsing, exploring, and “purchasing” cars online. Users can filter cars by brand, view detailed images, and simulate a shopping experience.  

**Development Highlights:**  
- Built with **`HTML`**, **`CSS`**, & **`JavaScript`**  
- Utilizes **JSON** to manage product data dynamically  
- Responsive design for smooth browsing on desktop and mobile  

**Key Features:**  
- 🚗 Browse a wide range of cars with detailed images  
- 🔍 Filter and sort cars by brand, model, or type  
- 🛒 Simulated cart system for a realistic shopping experience  
- 🌙 Dynamic Dark/Light theme support for better user experience  

**Color Choice 🩷:**  
The interface uses **Pink** to give a vibrant, modern, and youthful feel, enhancing user engagement and visual appeal.
