### 3️⃣ 3ax El-Seer — *Reverse Path Puzzle (Web)*
---

**Overview:**  
A web-based interactive puzzle/game where users solve challenges to guide a virtual vehicle backwards. It features dynamic calculations and a small logic-based mystery embedded in the gameplay.  

**Development Highlights:**  
- Built with **`HTML`**, **`CSS`**, & **`JavaScript`**  
- Implements interactive buttons, dynamic calculations, and real-time feedback  
- Responsive design for desktop and mobile browsers  

**Key Features:**  
- 🧩 Logic-based puzzle that challenges users’ problem-solving skills  
- 🚗 Interactive "reverse path" navigation simulation  
- 🔄 Real-time updates as users input values or solve steps  
- 🕵️‍♂️ Hidden mystery/mini-riddle to enhance engagement  

**Color Choice 🩶:**  
The UI uses **Gray** to give a neutral, balanced look that emphasizes the puzzle elements and keeps focus on problem-solving rather than flashy colors.
