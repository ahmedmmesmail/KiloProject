### 7️⃣ Es2al Mgarab — *Quizzes App*
---

**Overview:**  
An interactive Android quiz application featuring a variety of topics and question types. It provides users with an engaging way to test their knowledge and view their final score upon completion.

**Development Highlights:**  
- Built with **`Kotlin`** & **`JetPack Compose`**  
- Integrated **`Gson`** for loading and parsing question data  
- Implemented a clean, intuitive UI with smooth navigation between questions  

**Key Features:**  
- ✅ Dynamic quiz generation with multiple categories  
- 🧭 Displays final score and performance summary at the end  
- 📊 Randomized question order to ensure fairness  
- 🌙 Dynamic Dark/Light theme support for better user experience

**Color Choice 💛:**  
The UI primarily uses **Yellow** to convey energy, optimism, and attention,  
enhancing user engagement and making the quiz experience visually lively and fun.
