### 🧭 Al-Boslah Da3et — Compass App
---
**Overview:**  
A simple and intuitive compass utility app for Android, built with Kotlin.  
It provides smooth rotation based on device sensors and a responsive UI for easy navigation.

**Development Highlights:**  
- Built with **Kotlin** using **accelerometer** and **magnetic field sensors**  
- Implements **low-pass filtering** to reduce compass vibrations  
- Dynamic and responsive UI with real-time azimuth updates  
- Dark/Light theme support for better user experience

**Key Features:**  
- 🧭 Real-time compass rotation  
- 📐 Displays numeric azimuth and cardinal direction  
- 🌙 Dark/Light theme support  
- 💡 Smooth and filtered sensor readings

**Color Choice 🩵:**  
The compass interface uses **Teal** to reflect clarity, calmness, and navigation.  
This color enhances **readability**, reduces visual strain, and creates a **pleasant, intuitive user experience**.
