# 🚀 KiloProject Phase 2

**KiloProject Phase 2** marks the next stage of my journey, expanding into **web development** and **advanced Android applications**.  
Across four distinct projects, I explored different technologies and architectures — from **HTML, CSS, JavaScript** for web apps to **Kotlin with Jetpack Compose** for Android applications.

Each project emphasizes **clean code**, **practical problem-solving**, and **user-centered design**, covering real-world use cases like calculator game, e-commerce platforms, quizzes, and compass utilities.

---

- 🧩 Build **interactive and responsive applications** for `web` and `Android`  
- ⚙️ Work with **modern technologies** including **Gson** for `JSON` parsing and **sensor handling** 
- 🔐 Implement **data handling**, **dynamic interfaces**, and **smooth interactions**
